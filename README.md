# Moneo

Simple full-stack budgeting tracker for paychecks and allocations.

## Features
- Track paycheck date and amount
- Track allocations into investment, savings, and spending accounts
- View on-the-fly charts for income and allocation categories
- Switch summary granularity between monthly and bi-weekly

## Run
```bash
node /home/runner/work/Moneo/Moneo/server.js
```
Then open `http://localhost:3000`.

## Test
